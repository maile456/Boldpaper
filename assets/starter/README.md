# goodthings / 好东西起步模板

这是 Boldpaper skill 附带的原创静态示例，视觉参考 Gumroad 的大色块、粗边框与硬阴影。可直接浏览，也可继续改成商店、作品集或落地页。

## 打开

双击 `dist/index.html` 即可查看。推荐使用 Node.js 18+ 运行 `npm run dev`，然后打开终端显示的本地地址；Windows 也可以双击 `start.cmd`。无需安装依赖。

`npm run check` 检查核心文件、静态资源链接和 JavaScript 语法。布局、真实交互和键盘操作另行在浏览器中验证。

## 修改

- `dist/tokens.css`：颜色、字体、边框、阴影。
- `dist/index.html`：品牌、导航、首屏与内容结构。
- `dist/styles.css`：组件、布局、响应式和视觉状态。
- `dist/app.js`：`PRODUCTS` 商品数据、`ART` 封面和交互。

`dist/` 就是源码目录，保留并直接编辑。素材使用相对路径，无外部字体或 CDN。

示例提供分类搜索、详情、本地收藏和真实样例文本下载。价格仅用于界面展示，下载免费。直接用本地文件方式打开时，收藏持久化取决于浏览器支持；使用稳定的本地服务地址更便于反复开发。

此示例是实现起点。按实际用途替换品牌、栏目、内容与功能，并同步修改本说明。
