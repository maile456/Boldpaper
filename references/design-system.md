# 视觉语言与组件参考

这套参考来自 goodthings / 好东西原创前端起步包。它提炼 Gumroad 的视觉特征，适用于有个性的创作者产品、作品集和落地页。内容结构随用途变化。

## 色彩角色

| Token | 默认值 | 角色 |
| --- | --- | --- |
| `--ink` | `#242323` | 文字、描边、硬阴影 |
| `--paper` | `#f5f1e8` | 阅读背景和留白 |
| `--pink` | `#ff90e8` | 品牌主色、重要分区 |
| `--yellow` | `#ffc900` | 强调区、贴纸与提示 |
| `--mint` | `#c5f1cf` | 次级分区与封面 |
| `--blue` | `#b8c8ff` | 次级封面与图形 |
| `--white` | `#ffffff` | 卡片与表单表面 |

用米白平衡鲜艳颜色。粉与黄可占据大块区域，绿与蓝形成局部变化；无需让每种颜色都成为主色。浅色底配深色文字，深色按钮配白色文字。选中状态除了颜色还应有可读标签、图形或状态属性。

用户指定新配色时，保留颜色的角色和足够对比度，集中调整 token，避免在每个组件中分散覆盖。

## 字体与比例

- 中文优先系统黑体，英文标题可以用 Arial Black；不依赖网络字体即可形成鲜明层级。
- 首屏标题建议手机约 36–48px、桌面约 56–80px，随文字长度调整；中文长标题允许自然换行。不要照搬短标题的 `white-space: nowrap` 到长标题。
- 正文从 16px、1.6–1.8 行高起步；辅助标签小而清楚。英文字距可紧，中文标题避免过度压缩。
- 装饰性的英文短句只作为调味，主要信息使用用户的语言。页面主张、解释和主行动应有明确层级。

## 轮廓与触感

```css
border: 2px solid var(--ink);
border-radius: 6px;
box-shadow: 5px 5px 0 var(--ink);
```

大分区用干净的深色分割线。普通组件圆角约 0–8px，胶囊主要用于分类和短标签。阴影不加模糊，避免用毛玻璃、满页渐变或柔光阴影稀释风格。

按钮悬停时小幅向左上位移，按下向右下位移，阴影跟随缩短；约 120–180ms 即可。遵循 reduced motion，移除非必要运动。文字正文和大面积装饰不用一直漂浮或循环滚动。

## 页面构图

首屏可以用粉色文案区与黄色原创插画区构成对照，也可以用单栏超大排版；选择最适合信息的方式。后续使用较平静的背景呈现具体内容，再以彩色区块收尾。

桌面主要内容宽度约 1200–1280px。内容网格常见 3 / 2 / 1 列；根据内容宽度设断点。手机上重排首屏、筛选栏和行动按钮，缩减装饰密度。保留足够外侧间距，同时避免长名称挤压价格和操作。

原创素材可以是矢量花朵、几何形状、文字封面、书本、纸张、贴纸。大面积视觉应服务于产品意义；不要把全部页面都堆成相同卡片或在每个角落放星星。

## 商店组件参考

仅在产品目录类任务中沿用这些模式：

- 商品封面统一比例但构图不同，下方是分类、标题、简短说明，底部是作者、价格与收藏。
- 分类与搜索同区排列，选中分类有填充和状态标记；搜索后保持筛选条件，显示结果数量。
- 详情弹窗延续对应商品封面，清楚列出内容和操作；窄屏内容可滚动，关闭按钮始终可达。
- 收藏有空状态，移除当前卡片后焦点留在结果区域。
- 演示下载使用真实生成的样例文件，按钮与说明明确表达样例性质。

作品集、工具和落地页应替换为各自的内容模型。只迁移视觉与适用组件，不强行添加商店价格、收藏或下载流程。
